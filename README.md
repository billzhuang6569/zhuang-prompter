# 庄Sir的提词器

一款为视频创作者、知识博主、课程录制者和小型拍摄团队设计的本地提词器。

它让你用一台电脑编辑和控制文稿，让另一块屏幕、另一台电脑、iPad 或手机显示提词内容。优先通过本地局域网工作，不需要账号，不需要云端服务器，也不默认上传文稿。

![庄Sir的提词器产品主视觉](https://pictshare.whatonearth.work/nvp5r4.png)

## 一句话介绍

庄Sir的提词器是一套“控制端 + 播放端”的提词工作台。

控制端负责写稿、改稿、保存、跳段和控制播放；播放端负责给被拍摄者显示清爽的大字提词画面。两端在同一个 Wi-Fi、热点或局域网内同步工作，适合真实拍摄现场。

## 适合谁使用

| 使用者 | 典型场景 | 解决的问题 |
| --- | --- | --- |
| 知识博主 | 录制口播、选题讲解、产品介绍 | 减少忘词、卡壳、重复录制 |
| 课程创作者 | 录课、线上课、训练营内容 | 长稿分段清晰，章节快速跳转 |
| 小型拍摄团队 | 一人控制，一人出镜 | 现场可改稿、可暂停、可跳段 |
| 访谈和直播团队 | 开场稿、串词、嘉宾提示 | 播放端只显示嘉宾需要看的内容 |
| 本地优先用户 | 不想上传脚本到云端 | 文稿保存在自己的电脑上 |

## 为什么它不只是一个“滚动文字工具”

很多提词器只解决“把文字滚起来”这件事。但真实拍摄里，麻烦通常出现在这些地方：

- 临时改词，播放端不能及时同步
- 长稿找不到段落，只能反复拖动
- 录到一半要重来，不知道从哪里继续
- 提词器镜像方向不对，现场调试很浪费时间
- 文稿、备注、标记点分散在不同工具里
- 不想把未发布脚本上传到云端服务

庄Sir的提词器把写稿、标记、备注、播放控制、播放端同步放在同一个工作流里，让拍摄现场更稳。

## 核心工作流

![本地局域网多端同步示意](https://pictshare.whatonearth.work/n5gle4.png)

1. 在控制端创建一个房间。
2. 在控制端编辑文稿、添加标记点和备注。
3. 播放端扫码或打开网址加入同一个房间。
4. 控制端开始播放，并控制速度、暂停、跳转、镜像和全屏。
5. 文稿和设置保存在本机，下次可以继续使用。

一个房间可以理解为一个拍摄项目。不同视频、课程、直播或发布会，都可以分别创建自己的房间。

## 功能亮点

![控制端与播放端功能示意](https://pictshare.whatonearth.work/b8bqwc.png)

### 1. 控制端：拍摄现场的操作台

控制端是创作者、导演或助理使用的页面。它负责文稿创作和播放控制。

- 创建和打开不同项目房间
- 直接编辑 Markdown 文稿
- 使用渲染后的文稿视图，减少面对原始代码的负担
- 添加标记点，用于快速跳到章节、重录点、重点段落
- 添加备注，用于提示看镜头、停顿、语气、镜头或后期处理
- 保存草稿和历史版本
- 控制播放端播放、暂停、回到开头、跳到结尾
- 调整自动滚动速度
- 跳转到指定标记点
- 控制播放端水平镜像、垂直镜像
- 复制播放端网址，方便另一台设备加入

### 2. 播放端：给出镜者看的清爽提词画面

播放端只做一件事：让被拍摄者轻松读词。

- 大字号显示文稿
- 支持自动滚动
- 支持全屏显示
- 支持水平镜像和垂直镜像，适配硬件提词器反射镜
- 默认隐藏标记点，避免干扰朗读
- 需要时可以显示标记点
- 可通过控制端远程播放、暂停、跳转和调速

### 3. 标记点和备注：让长稿更好拍

你可以在文稿中加入简单标记：

```markdown
::marker[01]{text="开场"}

::notes{text="这里看镜头，语速放慢一点"}
```

标记点适合用于章节跳转，例如“开场”“重录点”“结尾总结”。  
备注适合给自己、摄影同事或后期同事看，例如“看镜头”“这里停顿 1 秒”“这段可以重录”。

### 4. 本地优先：文稿默认留在你的电脑上

当前版本不要求登录账号，不依赖远程数据库。

这意味着：

- 房间数据保存在你的电脑上
- 文稿不会默认上传到云端
- 没有外网也可以在局域网内使用
- 拍摄现场更少受服务器状态影响

未来如果需要团队账号、远程协作、云端模板库和跨设备同步，可以再引入服务器方案。当前版本先把本地拍摄这条主线做好。

### 5. 语音辅助滚动

当前版本包含实验性的语音辅助滚动。

它不是完全用语音识别替代滚动，而是在自动滚动的基础上，根据你实际朗读的位置辅助调整滚动速度，让文稿尽量贴近你的口播节奏。

这个功能仍在早期阶段。正式拍摄前，建议先试读一遍，确认麦克风和浏览器权限正常。

## 快速开始

### 第一步：打开应用

启动“庄Sir的提词器”。

应用会自动在你的电脑本地启动一个提词服务。你不需要手动配置服务器，也不需要先安装开发环境。

### 第二步：创建房间

在首页创建一个新房间。

一个房间可以对应：

- 一条视频
- 一节课程
- 一场直播
- 一次发布会
- 一次拍摄任务

### 第三步：编辑文稿

进入控制端后，直接编辑文稿。

建议把文稿写成结构清晰的段落：

```markdown
# AI 到底是在猜，还是在想？

今天我们讲一个很多人都好奇的问题：AI 到底是在猜，还是在想？

如果你问一个大模型：“苹果为什么会落到地上？”
它会给你一个看起来非常合理的答案。
```

### 第四步：打开播放端

在控制端右侧找到播放端网址，复制到另一台设备，或用另一台设备扫码打开。

典型播放端网址类似：

```text
http://192.168.1.20:3000/room/123456/player
```

播放端设备需要和控制端电脑处在同一个 Wi-Fi、热点或局域网中。

### 第五步：开始提词

在控制端点击播放。

你可以随时暂停、调速、跳到某个标记点，或者切换播放端镜像模式。

## 常见拍摄场景

### 一个人录口播

控制端放在主电脑上，播放端可以放在 iPad、手机、另一台电脑或外接显示器上。录制时只需要控制播放速度和段落跳转，播放端保持清爽大字。

### 小团队拍摄

导演、助理或制片使用控制端，嘉宾看播放端。现场需要改词时，控制端直接修改并保存，播放端同步更新。

### 长稿课程录制

长稿可以用标记点拆成多个章节。录制到某一段出错时，可以直接跳回对应标记点，不需要从头找。

### 使用硬件提词器反射镜

播放端支持水平镜像和垂直镜像。你可以根据硬件提词器的反射方式调整画面，避免文字方向不对。

## 局域网使用注意事项

如果播放端打不开，通常检查这几件事：

1. 控制端和播放端是否连接同一个 Wi-Fi 或热点。
2. 播放端网址里的 IP 是否是控制端电脑当前的局域网 IP。
3. 控制端电脑的防火墙是否允许应用被局域网访问。
4. 端口是否被其他软件占用。
5. 如果使用语音识别，建议优先在桌面应用的控制端里使用麦克风。
